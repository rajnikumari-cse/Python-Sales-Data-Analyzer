# Python Sales Data Analyzer

A simple sales data analysis project built using Python, Pandas, and Matplotlib.

## About

This project analyzes sales data to understand total sales, average order value, top-selling products, best-performing categories, and region-wise sales performance.

## Features

- Total sales calculation
- Total orders analysis
- Average order value
- Top-selling product
- Best-performing category
- Region-wise sales analysis
- Data visualization

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## Results

- Total Sales: ₹5,15,100
- Total Orders: 20
- Average Order Value: ₹25,755
- Top Product: Laptop
- Best Category: Electronics
